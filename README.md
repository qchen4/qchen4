# Jeremy Chen
Hi, I’m Jeremy Chen 👋 An FPGA engineer interested in digital design, computer architecture, and the hardware behind efficient computing. I work with Verilog/SystemVerilog, C/C++, and Python to build and verify systems—from RISC-V processors and cache subsystems to OFDM baseband pipelines and HLS accelerators. I enjoy understanding how things work at the RTL and cycle level, turning algorithms into hardware, and chasing down bugs one waveform at a time. 🐾
